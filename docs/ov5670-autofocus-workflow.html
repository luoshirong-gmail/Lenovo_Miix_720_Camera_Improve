模式转换规则

  • • manual → auto: 勾选 focus_auto (0→1 边沿)
  • • auto → manual: AfState 完成检测 (200ms 轮询) 自动回
  • • manual → continuous: stable 继承, 先判失焦再重扫
  • • continuous: 默认模式, 失焦连续 5 帧才重扫

触发语义

  • • af_trigger 是 int 控件非 button — 写 1 保持 1
  • • router 消费边沿后写回 0 → 下次 0→1 可再触发
  • • continuous 下触发被忽略 → 立即复位 0 (防残留)
  • • 触发后 300ms 复位 + 无重发 (ENOBUFS 已根治)
